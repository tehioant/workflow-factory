# Selected copied control

`src/lib/ui/button.svelte` is a reduced, project-maintained adaptation of the MIT shadcn-svelte Button (button-only, default/secondary variants, no unused link/size variants). Source: https://github.com/huntabyte/shadcn-svelte/blob/3c4152d7d3904e76f6f756ec8ffca7c9ec72f977/docs/src/lib/registry/ui/button/button.svelte . It uses Tailwind, tailwind-variants, clsx and tailwind-merge; this native button needs no Bits UI primitive. No CLI or entire component collection is included at runtime.
